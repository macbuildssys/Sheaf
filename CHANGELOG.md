# Changelog

## 0.0.1

First release.

* Library of recent and favorite files with grid and list views, thumbnails, details panel and sorting. Everything is reached by right click.
* Tags, favorites and custom groups that match by file type, folder or tag.
* Search language with words, phrases, exclusions and the operators tag:, type:, in:, is:fav and is:missing.
* Quick open window and a command line tool.
* Import of favorites and groups from Thingy, and export and import of the library as JSON.
* Reading progress for PDF and EPUB files where it is available.
* Debian package with desktop file, AppStream metadata, man page and bash completion.
